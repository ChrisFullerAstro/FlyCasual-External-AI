# Actions and Tokens

## When Actions Are Performed
- After executing a maneuver during Activation Phase
- A stressed ship cannot perform actions (except purple actions if available)
- A ship that bumped another ship cannot perform actions

## Standard Actions

### Focus
- Gain 1 focus token
- Spend focus token: Change all focus results to hits (attacking) or evades (defending)
- Focus tokens are removed during End Phase

### Evade
- Gain 1 evade token
- Spend evade token: Add 1 evade result when defending
- Evade tokens are removed during End Phase

### Target Lock
- Acquire a lock on an enemy ship at Range 0-3
- Lock persists until spent or the target is destroyed
- Spend lock: Reroll any number of attack dice against that target
- Can only have one lock on each enemy ship

### Barrel Roll
- Move the ship laterally using the 1-straight template
- Used to adjust position without changing facing
- Must end without overlapping ships or obstacles

### Boost
- Execute a 1-straight, 1-bank left, or 1-bank right maneuver
- Used to extend movement or adjust position
- Must end without overlapping ships or obstacles

### Rotate Arc
- Rotate a turret arc indicator to a different position
- Used to aim mobile weapons in different directions

### Reinforce
- Gain a reinforce token (fore or aft)
- When defending, if attack is through reinforced arc, add 1 evade result
- Removed during End Phase

### Coordinate
- Choose a friendly ship at Range 1-2
- That ship performs a free action

### Jam
- Choose an enemy ship at Range 1
- That ship gains 1 jam token
- Jam token removes 1 green token or breaks 1 lock when gained

### Calculate
- Gain 1 calculate token (droids)
- Spend calculate token: Change 1 focus result to hit or evade
- Calculate tokens are removed during End Phase

### Cloak
- Gain cloak token, roll 2 extra defense dice
- Must decloak at start of Activation Phase

## Red Actions
- Red actions cause the ship to gain 1 stress token after performing
- Cannot perform red actions while stressed

## Linked Actions
- Some ships can perform a second action linked to the first
- Shown as action -> linked action on ship card
- Linked action is often red
