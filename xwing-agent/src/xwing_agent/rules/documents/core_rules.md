# X-Wing Core Rules

## Game Overview
X-Wing is a tactical ship-to-ship combat game where players control starfighters in the Star Wars universe. The game is played on a 3' x 3' play area.

## Round Structure
Each round consists of these phases in order:
1. **Planning Phase** - Secretly select maneuvers for all ships
2. **System Phase** - Activate abilities that trigger during System Phase
3. **Activation Phase** - Ships reveal dials and execute maneuvers in initiative order (lowest first)
4. **Engagement Phase** - Ships attack in initiative order (highest first)
5. **End Phase** - Remove circular tokens, ready exhausted cards

## Initiative
- Ships have initiative values from 0-6 (some special abilities can modify this up to 12)
- **Activation Phase**: Lower initiative moves FIRST (0, 1, 2... 6)
- **Engagement Phase**: Higher initiative attacks FIRST (6, 5, 4... 0)
- Ties are broken by player order (first player chooses order among ties)

## Ship Stats
- **Initiative**: Determines activation and engagement order
- **Attack**: Number of attack dice rolled
- **Agility**: Number of defense dice rolled
- **Hull**: Damage capacity before destruction
- **Shields**: Absorb damage before hull (regenerable by some abilities)

## Winning the Game
- Standard: Destroy all enemy ships
- Tournament: Most points after 75 minutes (destroyed enemy ships + half points for damaged ships)
- Half points awarded when a ship has lost half or more of its combined hull + shields
